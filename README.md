# Crazy Vegetable Race

Crazy Vegetable Race est un jeu inspiré de Flappy Bird. Votre objectif est d’obtenir un maximum de pièces afin de débloquer le plus de légumes possible dans votre collection. Plus vous progressez, plus la vitesse augmente et plus le jeu devient compliqué.


## Cloner et lancer le jeu

```bash
# Cloner le dépôt
git clone https://ytrack.learn.ynov.com/git/baymeric/Puissance4.git

# Se déplacer dans le dossier du projet
cd Crazy_Vegetable_Race

```

Ouvrez simplement `public/index.html` dans votre navigateur.

Vous pouvez egalement lancer un serveur local :

```bash
python3 -m http.server 8000
```

Puis ouvrez : `http://localhost:8000/`

## Technologies utilisées

| Technologie     | Rôle                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------- |
| **HTML**        | Structure les pages du site et l’interface du jeu.                                              |
| **CSS**         | Gère la mise en page, les couleurs et les animations.                                           |
| **JavaScript**  | Gère toutes les interactions du jeu, la progression, les niveaux et le dynamisme.               |
