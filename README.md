# Crazy Vegetable Race

Petit jeu web en HTML, CSS et JavaScript.

## Lancer le projet

Ouvre simplement `public/menu.html` dans ton navigateur.

Tu peux aussi lancer un serveur local :

```bash
cd public
python3 -m http.server 8000
```

Puis ouvre : `http://localhost:8000/menu.html`

## Contrôles

- Clic gauche : sauter
- Espace : sauter
- Flèche haut : sauter

## Sauvegarde

Le meilleur score, les pièces et les skins sont sauvegardés dans le `localStorage` du navigateur.
